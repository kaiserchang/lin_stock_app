# 📈 林家洋技術分析 - 全市場掃描雷達 (v8.3 實戰週線宏觀與破億防護旗艦版)

這是一個基於 Python 與 Streamlit 開發的輕量化、高容錯台股技術分析儀表板。系統將技術分析名師林家洋的核心理論（力竭原理、K線組合、趨勢位置、攻擊K線、大底破繭、多週期共振）進行深度量化，並具備航太級的多層級備援抓取機制，讓投資者能快速且穩定地掃描全市場，精準捕捉具備高安全邊際與波段爆發力的頂級起漲訊號。

---

## 🎯 一、 林家洋技術分析核心型態庫 (Core Signals)

本系統全面升級為多週期雙軌架構，涵蓋以下核心型態與量化評分機制：

### 1. 👑 大底破繭 (長期整理突破) —— 【120 分 頂級起漲先鋒】
- **核心精髓**：林家洋前輩傳授——「最好的股票還是要有長期整理，然後剛剛開始突破的股票」。
- **量化條件**：
  - 時間維度：過去 40～60 個交易日處於打底整理狀態（箱型震盪振幅 $\le 22\%$）。
  - 均線糾結：月線 (MA20) 與季線 (MA60) 差距 $\le 4.0\%$，均線充分纏繞走平。
  - 突破確認：當日實體紅K（漲幅 $\ge 2.5\%$），成交量放量達 5 日均量 1.8 倍以上，實體收盤價突破過去 40 日箱頂！
  - **剛性防護**：必須同時通過「單日成交金額 $\ge 1.0$ 億元」、「上方 250 天無歷史巨量套牢」與「週線未走空」。基期極低、上方無浮額，為勝率與期望值最高之起漲點。

### 2. ⚡ 順勢強攻 (扭轉突破 / CHoCH) —— 【100 分 破底翻起漲先鋒】
- **核心精髓**：下降慣性破壞。在下降趨勢（高點越來越低、低點越來越低）力竭後，伴隨高成交量實體突破前波反彈高點，打破空方結構之破底翻起漲點。
- **剛性防護**：成交金額 $\ge 1.0$ 億元，排除連漲力竭出貨K，排除週線空方段。

### 3. 🚀 順勢強攻 (突破高點 / 攻擊K線) —— 【100 分 初升段強攻先鋒】
- **條件**：股價位於季線 (MA60) 之上，當日實體紅K漲幅 $\ge 3.0\%$，成交量達 5 日均量 1.5 倍以上，實體突破近 20 日波段高點。
- **首日突破限制**：限於「底部/橫盤 10 天以上剛發動的第一根紅K」，嚴格排除過去 5 天已連續大漲 2 天以上的力竭出貨K。

### 4. 🔥 多頭反轉 (吞噬賣壓 / 多頭吞噬) —— 【75 分 高勝率轉折先鋒】
- **條件**：股價位於季線 (MA60) 之上，前日為黑K，當日紅K實體完全包覆前一日黑K實體。
- **大數據實證**：回測顯示回檔洗盤完畢後的轉折點，**T+5 賺錢勝率高達 70.3%**！買點安全，不易被隔日沖砸盤。

### 5. 🔋 多頭蓄勢 (蓄力中 / 內困型態) —— 【30 分 籌碼沉澱觀察】
- **條件**：季線之上出現價格範圍包覆於前日K棒內的 Harami 型態，量能萎縮。大漲後的良性洗盤，等待帶量突破母K高點再行進場。

### 6. ⚠️ 跌破趨勢 (波段停利) —— 【-60 分 林家洋核心停利點】
- **條件**：上升趨勢中，股價收盤實體跌破波段拉回低點連線（上升趨勢線），或實體跌破前波次低點（Higher Low 階梯防守點）。代表多方墊高慣性終結，果斷獲利了結！

### 7. ⏳ 弱勢反彈 (空頭壓制) —— 【15 分 空頭陷阱禁止買進】
- **條件**：股價位於季線 (MA60) 之下，或處於週線空方修正段時出現的反彈或吞噬。上方均線下彎反壓沉重，**多單嚴禁進場**。

### 8. 💣 黑K吞噬 (逃命警示) —— 【-60 分 絕對警戒停損】
- **條件**：長黑K實體完全包覆前日紅K實體。主力高檔出貨訊號，持股無條件停損或停利結案。

## 🛡️ 二、 實戰買進 6 大前置硬性阻斷濾網 (Hard Filters)

所有掃描標的進入 TOP 5 候選池前，必須通過以下 6 大硬性濾網，任何一項觸犯即「一票否決」：

1. 🛑 **短線暴衝與力竭過濾**：近 20 日累積漲幅 $> 25.0\%$ 或 短線 5 日急漲 $> 20.0\%$ ➔ **一票否決**！
2. 📏 **季線乖離過濾**：季線正乖離率 $> 18.0\%$ ➔ **一票否決**（黃金安全區間為 $+1.0\% \sim +12.0\%$）。
3. 📊 **剛性流動性與破億門檻**：5 日均量需 $\ge 800$ 張，當日成交量需 $\ge 1,200$ 張，**單日成交金額必須 $\ge 1.0$ 億元台幣** ➔ 未達 1 億一票否決（徹底排除平時無量、偶爾炒作之小型妖股）。
4. 🚫 **上方 250 天歷史巨量套牢反壓過濾 (250D Overhead Supply)**：過去 1 年內曾自歷史高點暴跌超過 $28\%$ 且上方存在巨量套牢山頭者 ➔ **一票否決**（排除如華經這類高空套牢深水區反彈股）。
5. 📈 **週K線宏觀趨勢共振過濾 (Weekly Trend Filter)**：週 5MA 走平翻揚、打出週線 Higher Low 雙底者優先；凡最新週K收在週 5MA 之下且週 5MA 下彎、或高檔見頂下挫者 ➔ **一票否決**（排除如華碩自高檔見頂的下跌波段）。
6. 🌊 **族群共振加權**：同產業有 2 檔以上同時表態者優先決選。

## 🛡️ 三、 實戰持股四大防線體系 (v3.1 有狀態出場紀律)

1. 🛑 **第一道防線：攻擊K低點防守 (-3.5% 保命停損)**  
   - **判定標準**：以 **13:10～13:20 尾盤收盤實體** 是否跌破發動K低點為唯一依據。  
   - **防主力洗盤禁令**：**嚴禁預掛盤中窄幅條件觸價單（Stop Order）**！盤中任何跌破皆屬過程，未收盤前不被主力開盤 09:05 下影線洗在阿呆谷（鴻準實戰教訓）。
2. 📉 **第二道防線：季線 MA60 終極多空分水嶺**  
   - 實體收破 60MA 季線，波段趨勢破壞，多單全數停損結案。
3. 💰 **第三道防線：雙數張階梯移動保本與趨勢線防守**  
   - 雙數張操作時序：第 1 張衝高達 $+5\% \sim +8\%$ 獲利落袋鎖死勝率；**第 2 張「同一時間」將防守底線上移至「買進平均成本價（保本）」**，確保該筆交易 100% 零風險，絕不讓賺錢單變賠錢單！
4. ⏳ **第四道防線：T+5 時間防線硬性換股 (杜絕資金鈍化)**  
   - 持股滿 **5 個交易日 (T+5)**，若股價仍在成本 $\pm 2.0\%$ 內牛皮停滯且推薦分數降為 0 分：**第 5～6 天必須在平盤附近主動結案換股**，將資金釋放給新的 TOP 5 標的，嚴禁以未破停損為由盲目死抱！

## ✨ 四、 系統特色與架構優化 (System Architecture)

- **📈 多週期週線重採樣**：自動將日線資料以每週五收盤重採樣為週K線，計算週 5MA/10MA/20MA 及斜率，確保「大週期定方向、小週期找買點」。
- **⏱️ 400 天長週期歷史深度**：資料抓取窗口擴大至 400 日，完整覆蓋 250 個交易日（1 年）籌碼套牢反壓檢測與 52 週週線分析。
- **🛡️ 航太級三層備援抓取 (Multi-Tier Fallback)**：`yfinance` 遭遇 API 封鎖或上櫃股識別失敗時，自動切換至「台灣證交所 (TWSE)」與「櫃買中心 (TPEx)」進行資料救援。
- **🚨 即時大盤空頭避險開關**：加權指數收破 20MA 或單日重挫 $> 1.0\%$ 時，系統強制啟動 BEAR_DEFENSE，全面關閉追價買單。
- **🌙 沉浸式暗黑 UI**：專為長時間盯盤設計的高對比暗藍色背景 (`#0B1120`) 與直覺式狀態燈號。

## 🚀 五、 執行應用程式 (Usage)

在專案虛擬環境啟動狀態下，於終端機輸入：
```bash
streamlit run app3.py
```
系統將自動開啟瀏覽器並連線至 `http://localhost:8501`。
